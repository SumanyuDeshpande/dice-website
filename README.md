## 📖 About

This repository contains the source code for the **official website** of **DICE (Desktop Intelligent Cognitive Engine)**.

The website serves as the public face of the project, providing visitors with:

- Project overview
- Features and capabilities
- Documentation
- Installation guides
- Download links
- Screenshots
- Project roadmap
- Contribution information
- Latest updates

This repository **does not contain the DICE application itself**.

For the desktop assistant source code, please visit the main repository.

👉 **Main Repository:**  
https://github.com/SumanyuDeshpande/DICE

---

## ✨ Purpose

The website is designed to:

- Showcase DICE and its capabilities.
- Provide a centralized documentation hub.
- Help new users get started.
- Direct contributors to the main repository.
- Share future updates and releases.

## 🛠️ Running Locally

Clone the repository:

```bash
git clone https://github.com/SumanyuDeshpande/DICE-Website.git
```

Navigate into the project:

```bash
cd DICE-Website
```

Open `index.html` in your browser or use a local development server such as the VS Code Live Server extension.
